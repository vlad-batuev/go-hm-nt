# Многопоточный обработчик логов веб-сервера

## Описание
Программа для параллельной обработки логов веб-сервера, реализованная на Go с использованием горутин, каналов и паттерна Worker Pool.

## Функциональность
- Чтение логов из CSV файла
- Параллельная обработка с использованием пула воркеров
- Фильтрация записей по статус-коду (только ошибки 4xx и 5xx)
- Подсчет статистики:
  - Общее количество запросов
  - Количество ошибок
  - Среднее время ответа
  - Топ IP-адресов по количеству запросов

## Требования
- Go 1.21 или выше

## Структура проекта
log-processor/

├── processor.go # Логика обработки логов
├── testdata/
│ └── logs.csv # Тестовые данные
├── go.mod # Файл модуля Go
